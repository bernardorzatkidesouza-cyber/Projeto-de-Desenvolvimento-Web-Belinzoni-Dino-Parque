# Backend + Painel ADM – Belinzoni Dino Parque

Node.js + Express + PostgreSQL. Login por e-mail e senha (bcrypt + JWT).

1. `npm install`
2. Copie `.env.example` para `.env` e preencha
3. `npm start`
4. Painel: http://localhost:3001/admin

Níveis: `master` gerencia tudo e cria outros admins; `editor` gerencia só notícias.
